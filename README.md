# Project War

1-5 player co-op mercenary-company game, built as a Discord Activity. Side-view combat with live 3D fighters drawn as pixel art.

- `game/`: combat test (sim, rendering, menu)
- `rig/`: 3D fighters (humantest bundle + Project War rig, armor, poses)
- `animator/`: the Animator tool
- `dist/`: built single-file pages (`game.html`, `animator.html`)
